SOC TOOLKIT CHEAT SHEET
Tools:     SOC Toolkit (macOS edition) - web tools and ./soc command-line tools
OS:        macOS (Docker Desktop, Apple Silicon or Intel). Commands run in Terminal from the toolkit folder.
Generated: 2026-10-15

Conventions
  Run every command from the toolkit folder:
    cd "~/Documents/Guides and Scripts/30_Toolkits/soc-toolkit-macos"
  Evidence goes in ./cases on the Mac. Inside every tool it is /case.
  ./soc <tool> starts a throwaway container and removes it when the command ends.
  Secrets and ports live in .env (never commit or email it).
  DETECTIONS_DIR in .env (your detections repo) appears as /detections in sigma, detections and snort.
