Web tools open in the service tab. Command-line cards copy a ready-to-run ./soc command: run it in Terminal from the toolkit folder, with evidence in cases/ (seen as /case). External sites open in a new tab.

First time here? Accounts, first runs & safe handling+

BloodHound CE: sign in as admin with BLOODHOUND_ADMIN_PASSWORD from .env; you must set a new password at first login. Upload SharpHound/AzureHound ZIPs from Administration → File Ingest.

MobSF: sign in with mobsf / mobsf and change it under the account menu. Uploads are analyzed statically; dynamic analysis is not available in Docker on a Mac.

OWASP Nettacker: paste NETTACKER_API_KEY from .env into the key box. Scan only systems your organization owns or you are authorized to test.

ClickGrab and Email Check: no account. Both contact the site or mail server you submit, from this Mac's public IP.

Command-line tools build on first use. Build them all ahead of time (Ghidra takes 10–20 minutes):

docker compose --profile cli --profile ghidra build

Availability means the web service responds. It does not verify logins or every feature. The full command reference is in SOC-TOOLKIT-CHEATSHEET.txt.
